# Flex Space

משחק אינטרנטי קצר ללימוד ותרגול Flexbox, בנוי ב-HTML, CSS ו-JavaScript בלבד (ללא ספריות חיצוניות).

## על המשחק

בכל שלב מוצג לוח עם מספר חלליות והוראה שמתארת כיצד יש לסדר אותן.
המשתמש בוחר ערכים למאפייני Flexbox, בודק את הפתרון, ומתקדם לשלב הבא.

## מבנה הפרויקט

```
index.html      – מבנה העמוד
css/style.css   – עיצוב ופריסה
js/levels.js    – הגדרות השלבים
js/game.js      – לוגיקת המשחק
```

## הרצה מקומית

פתיחת `index.html` בדפדפן. אין צורך בשרת או בהתקנות.
